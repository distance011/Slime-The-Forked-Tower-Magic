# 史莱姆团 · 报名查询

史莱姆团发车表的玩家报名查询网站。
输入玩家名或 QQ，查询报名了哪些车表、在哪个队伍、打什么位置。

## 使用

访问：**https://distance011.github.io/Slime-The-Forked-Tower-Magic/**

输入**游戏ID 或 QQ号**即可查询：
- 报名了哪个车表、时间、车头
- 所在队伍（A队/B队/C队/1队/2队/3队）
- 主职 / 副职
- 一键打开对应车表的在线名单

## 数据说明

- 数据由团管理定期从各车表名单汇总生成
- 查询结果反映最近一次更新的数据
- 名单有变动时，数据会更新

## 隐私提示

本网站会公开展示报名玩家的游戏名、QQ 等信息，仅限团内使用，请勿外传链接。

## 部署

- 本仓库 `master` 分支存放网站源文件
- `gh-pages` 分支为 GitHub Pages 静态站点（`index.html` + `data.json`）
- 更新数据：团管理在本地更新 `site/data.json` 后推送即可
